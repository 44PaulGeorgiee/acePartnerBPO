# Planned public pages

These page routes are reserved in `../architecture.json`:

- `pricing.html` — packages, inclusions, exclusions, and calculator assumptions
- `how-it-works.html` — verified sales, hiring, onboarding, and delivery steps
- `privacy.html` — privacy notice reviewed for the operating jurisdictions
- `terms.html` — approved service, guarantee, and commercial terms
- `thank-you.html` — shown only after a lead is successfully accepted

Create a page only when its copy and behavior are ready. Keep shared assets relative to `src/` (for example `../styles.css` from this folder) and keep navigation paths consistent with `architecture.json`. Do not publish placeholder legal text as final policy.

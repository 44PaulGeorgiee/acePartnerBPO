# Verification plan

Add automated coverage here as a test runner is selected. At minimum, cover:

- calculator outputs and currency changes
- lead form required fields, invalid inputs, server rejection, and retry behavior
- meeting slot selection, timezone handling, unavailable slots, and network errors
- anti-abuse and rate-limit behavior
- analytics consent and prevention of PII collection
- admin authentication and authorization
- keyboard/mobile navigation and page links

Use synthetic test data only. Do not submit real customer information to test environments.

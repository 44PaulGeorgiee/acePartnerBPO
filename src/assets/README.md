# Asset upload locations

Upload approved, optimized public assets to these folders:

- `brand/` — logo variants, favicon, and approved brand files
- `case-studies/` — customer-approved case-study images and graphics
- `testimonials/` — headshots or logos with publication consent
- `trust/` — office, team, and independently verifiable trust evidence
- `legal/` — approved downloadable privacy, service, and policy documents

Use descriptive lowercase kebab-case filenames, for example `cebu-office-front.webp`. Record the relative asset path in its matching JSON record under `data/`. Do not upload secrets, private customer data, or unapproved photos.
